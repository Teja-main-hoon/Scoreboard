Scoreboard Overlay Instructions

1. Set up your Google Sheet

  1. Create a new Google Sheet.
  2. Enter team names in the first row and scores in the second row (Horizontal format).
  3. Click Share (top right).
  4. Change "Restricted" to "Anyone with the link".
  5. Copy the URL from your browser address bar.

2. Run the App

Double-click the Scoreboard Overlay app icon in this folder.

Note: On Mac, you may need to right-click and select "Open" the first time if you see a security warning.

3. Start the Scoreboard

  1. Paste your Google Sheet URL into the setup panel.
  2. Set the number of Teams.
  3. Click START.

The overlay will minimize to the bottom of your screen and stay on top of other windows automatically!
